# PROJECT.md

## Project
Advanced CV & Cover Letter Builder Platform

## Purpose
Build a web application for creating, editing, analyzing, managing, and sharing professional CVs and cover letters.

## Main Pages
1. Home
2. Register / Login
3. Dashboard
4. Your Projects
5. Advanced CV Builder
6. CV Templates
7. Cover Letter Builder
8. User Profile
9. Deleted Files
10. Logout

## Main Features
- React-based document creation and editing
- Overleaf-style advanced CV workspace
- ATS compatibility analysis
- Job description matching
- Resume content analysis
- Local AI writing assistant
- Career Profile Vault
- PDF, DOCX, and ZIP exports
- Project and file management
- Sharing and collaboration
- Autosave and version history

All features must use free and open-source technologies.
