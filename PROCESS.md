# PROCESS.md

## Development Workflow
1. Read `AGENTS.md`, `PROJECT.md`, and `ARCHITECTURE.md`.
2. Check `PROGRESS.md`.
3. Read the relevant module `.md` file.
4. Review existing code before making changes.
5. Develop one module or feature at a time.
6. Reuse components and avoid duplicate code.
7. Implement frontend, backend, and database changes where required.
8. Test functionality and fix errors.
9. Update relevant documentation.
10. Update `PROGRESS.md`.

## Rules
- Follow existing architecture.
- Use only free and open-source dependencies.
- Never delete working features without approval.
- Do not develop unrelated features.
- Avoid unnecessary code and dependencies.
- Keep code secure, responsive, and maintainable.
